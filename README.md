# THUNDER PAW CHESS — 3D版

添付された6体の猫を題材にした、ブラウザで遊べる3Dチェスです。盤上の猫と装備はThree.jsで描画する実際の立体メッシュです。

## 起動

Node.js 22.13以降を使用してください（テストはNode.js 24推奨）。このフォルダーで実行します。

```sh
npm ci
npm run dev
```

ブラウザで http://localhost:3000 を開き、CPU対戦またはふたりで対戦を選んで「対局をはじめる」を押してください。

```sh
npm run build
node --experimental-strip-types --test tests/chess.test.mjs
npx tsc --noEmit
```

## 実装済み

- 8×8盤、各陣営16駒。指定順のクイーン・キング・ナイト・ルーク・ポーン・ビショップ。
- アイボリー／ゴールドとチャコール／アンティークゴールドの立体メッシュ。厚みのある盤面、照明と影。ドラッグ回転、ピンチ・ホイール・ボタン拡大縮小、視点リセット。
- 同一端末の2人対戦、初級CPU対戦（人間が白、2手先までの評価）。
- クリック／タップ選択、合法手、直前の一手、選択した駒の日本語名と動き方。
- 手番、チェック、勝敗、引き分け、捕獲した駒、SAN棋譜。
- キャスリング、アンパッサン、4種の昇格選択。自玉をチェックにさらす手を禁止。
- チェックメイト、ステイルメイト、戦力不足、3回反復、50手ルール、2人対戦での合意引き分け。
- 新規対局、モード選択、盤面反転、短い移動アニメーション、捕獲時の光。
- スマートフォン対応、キーボードフォーカス、日本語ラベル、動きを減らすOS設定への対応。

## 構成と素材の差し替え

- `public/pieces/{queen,king,knight,rook,pawn,bishop}-{w,b}.png`: 駒の透過素材。
- `lib/chess/characters.ts`: 日本語名称、画像パス、説明の対応表。
- `lib/chess/engine.ts`: chess.jsの終局表示とCPUの評価。
- `components/chess/Board.tsx`: WebGL表示、視点操作ボタン、キーボード用マス選択。`lib/chess/three/scene.ts`: 3D盤面・カメラ・レイキャスト・移動と捕獲アニメーション。`lib/chess/three/figurines.ts`: 6種類×2色の立体造形と材質。後からGLB等に置換する場合はcreateFigurineLibraryのcreate関数を交換できます。
- `components/chess/ChessGame.tsx`: 対局状態と操作パネル。

画像は組み込みImageGenで添付画像を参照して背景除去・白黒バリエーション加工を行い、実際のアルファチャンネルを確認して分割・透明余白のトリミング・縮小をしました。元画像のピクセルをそのまま切り抜いたものではないため、細部や造形には差があります。これらの画像はプレイヤー表示・昇格候補・選択欄に使用し、3D盤上には使用していません。盤上は参照画像の特徴をもとに手続き的に立体を造形しています。厳密な3D復元ではなく、簡略化した造形です。プロンプトは `docs/image-prompts.json` と `docs/image-corrections.json` に記録しています。

## 検証

13件のルール／CPU／立体モデルテストが通過。立体モデルには幅・高さ・奥行きがあること、白黒が同じ形状であることを検証。3D盤で直接タップによる選択・移動・捕獲と、ドラッグで視点を回しても対局が進まないことを確認。ブラウザで2人対戦開始、双方の移動、捕獲、棋譜、CPU応手、4候補の昇格画面とナイト昇格、チェックメイト後の操作禁止、盤面反転を確認。390px幅で横はみ出しがないこと、画像がすべて読み込まれること、盤面の下に操作部が配置されることを確認しました。

## 制約

- CPUは初級のみ、人間が白。オンライン対戦や対局保存はなく、再読み込みで初期状態になります。
- 3回反復と50手ルールは自動で引き分けにします。大会規則の申告手続きや、その後の5回反復・75手まで続ける運用はありません。
- 時間制限なし。スマートフォンはブラウザの画面幅で検証し、実機全機種での検証はしていません。
- WebGL 2対応ブラウザが必要です。3D猫は添付の特徴を再構成した簡略モデルで、原画に忠実な精密彫刻ではありません。低い角度・高倍率では駒や盤の一部が重なるため「視点を戻す」で標準表示に戻せます。

ルール判定: chess.js 1.4.0 https://github.com/jhlywa/chess.js
